# State Transition Testing: Practical Examples

Practical examples demonstrating how to apply State Transition Diagrams to software test design. Each examples includes: 
* Requirements
* Questions & Assumptions
* State Transition Diagram (with direct link to draw.io)
* State Transition Table
* Coverage Summary Table
* Out of Scope  

---

## Overview of Examples

Select any topic below to view the detailed test design:

1. **[The Door Example](./std-door-example.md)**
   * **Description:** Building a State Transition Diagram directly from the requirements. A simple, linear entry-level scenario.
     
2. **[The Burglar Alarm Example](./std-burglar-alarm-example.md)**
   * **Description:** Constructing a State Transition Diagram from a state-transition table, including cycling transitions and loops. 

3. **[The Bank Account Example](./std-bank-account-example.md)**
   * **Description:** Deriving a State Transition Diagram from a bank account business algorithm.
